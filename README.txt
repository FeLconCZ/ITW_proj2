-- Informace o projektu --

Adresářová struktura:
složka img, kde jsou rozděleny obrázky do složek podle sekcí,
složka js, kde jsou všechny Scripty,
složka css, kde je soubor se styly,
poté jednotlivé soubory index.html a README.

Všechny obrázky jsou moje, až na obrázky v sekci Education a VUT FIT logo. Ty jsem stáhl z internetu.
Žádné speciální fonty jsem nepoužil, ale používám ikony z Font Awesome.

Originální nápad na layout stránky mám odtud: https://www.depoly.co/
Odkaz na veřejný github repozitář, ze kterého jde vidět postupný vývoj projektu: https://github.com/FeLconCZ/ITW_proj2
Použil jsem free github webhosting, protože když jsem už používal repozitář, tak hostování bylo docela jednoduché.
Layout jsem řešil většinou přes grid, protože mi přijde nejlepší a nejjednodužší.
Mimo grid jsem i používal column a na nav třeba flex.
Dalo by se říct, že stránka nevypadá úplně profesionálně, ale mě se líbí.
Jako vlastní webovou prezentaci si myslím, že je důležité, abych s tím byl spokojený sám.
Používám výrazné pozadí, a všechny sekce a obrázky z něj pěkně vyskakují.
Sekce používají box shadow na right a bottom, a díky tomu mají takový 3D vzhled.
Stránka je optimalizovaná na různou šířku displeje přes media screen.
Při menší šířce se mění navigace na hamburger menu, a všechny sekce se dají pod sebe.
Navigace je vždy viditelná, a při kliknutí na odkaz je hladný přechod k sekci.
Komentáře jsou v CSS pro přehlednost, v HTML nejsou, protože podle mě v mém kódu nejsou třeba.
Overall jsem s projektem spokojený, a líbí se mi.
